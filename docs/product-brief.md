# Product brief

See what we can discover. Understand where it is. Get to the correct exit when that destination has been independently verified.

One watched Solana mainnet public address at a time, paste-first. Ownership comes before markets, yield or promotions. USD is a known priced subtotal minus known debts, never universal net worth. Missing debts invalidate any lower-bound claim. Unpriced holdings remain visible. Rewards remain separate. Unknown protocol coverage and unverified destinations stay visible.

The UI uses a quiet midnight ledger: system fonts, midnight surfaces, mint accent, semantic disclosures, clear source and coverage panels, mobile card rows and desktop grouped lists. No signing, swaps, transaction construction, wallet approvals, custody, NFT gallery or fabricated PnL.
